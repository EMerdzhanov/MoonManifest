# Internationalization (i18n) Design Spec

## Overview

Add multi-language support to Moon Manifest using Flutter's built-in `flutter_localizations` + ARB file system. The app will support 11 languages with auto-detection from device settings and a manual override in the Settings screen.

## Architecture

### Infrastructure

**l10n.yaml** at project root:
- Template ARB: `lib/l10n/app_en.arb`
- Output class: `AppLocalizations`
- Output directory: default (`.dart_tool/flutter_gen/gen_l10n/`)

**ARB files** in `lib/l10n/`:
- `app_en.arb` — English template with all ~150 keys and metadata
- One ARB file per additional language (10 files)

**pubspec.yaml changes**:
- Add `flutter_localizations` SDK dependency
- Add `generate: true` under `flutter:` section

### String Key Organization

Keys prefixed by screen/context:

- `onboarding_*` — onboarding flow (welcome, cycle, phases, preferences)
- `waiting_*` — waiting screen (countdown, prep cards, draft section)
- `newMoon_*` — new moon screen (intention setting, guidance, grace period)
- `waxing_*` — waxing screen (progress, intention display)
- `fullMoon_*` — full moon screen (gratitude ceremony)
- `waning_*` — waning screen (release phase, daily wisdom)
- `philosophy_*` — manifestation philosophy screen
- `guide_*` — manifestation guide screen (4 rules)
- `settings_*` — settings screen (all options, dialogs)
- `history_*` — history screen (cycle cards, empty state)
- `lunar_*` — lunar cycle screen (phase descriptions, timeline)
- `cycle_*` — cycle progress bar (phase names, labels)
- `wisdom_*` — daily wisdom quotes (31 quotes with attributions)
- `common_*` — shared strings (Cancel, OK, error messages, phase names)

### Plurals and Placeholders

ARB plural syntax for language-specific plural rules:

```json
"daysAway": "{count, plural, =1{day away} other{days away}}",
"@daysAway": { "placeholders": { "count": { "type": "int" } } },

"intentionCount": "{count, plural, =1{intention} other{intentions}}",
"@intentionCount": { "placeholders": { "count": { "type": "int" } } },

"firstCycleMessage": "Your first cycle begins at the new moon on {date}.",
"@firstCycleMessage": { "placeholders": { "date": { "type": "String" } } },

"dayOfWaxing": "Day {current} of {total}",
"@dayOfWaxing": { "placeholders": { "current": { "type": "int" }, "total": { "type": "int" } } }
```

### Date Formatting

Already using `intl` package's `DateFormat` which auto-adapts to locale. No extra work needed — formats like `DateFormat('MMMM d')` will produce locale-appropriate output once the locale is set.

## Language Selection

### Auto-Detection

`AppLocalizations` resolves to the device language automatically. If the device language is not in our 11 supported languages, falls back to English.

### Manual Override

- New "Language" option in Settings screen, under existing sections
- Displays current language in its native name (e.g., "Български", "日本語", "हिन्दी")
- Tapping opens a selection list showing all 11 languages in their native names
- Selection persisted via `SettingsProvider` / `SharedPreferences`

### Implementation

- `AppSettings` model gets a nullable `locale` field (null = follow device)
- `SettingsRepository` persists the locale string
- `MaterialApp.router` wrapped with locale override from settings provider
- When user changes language, app rebuilds with new locale — all screens update instantly

## Translation Strategy

### UI Strings (~120 keys)

Standard buttons, labels, headings, descriptions. Direct translation for all 11 languages.

### Spiritual/Manifestation Content (~30 keys)

The guide screen (4 rules with examples), philosophy screen (waning explanation, sacred phases), and onboarding phase descriptions. Translated with cultural sensitivity:

- "I AM" declarations use culturally appropriate equivalents
- "Plant your intentions", "Release and trust" use natural spiritual language per culture
- For Chinese, Japanese, Hindi where manifestation terminology has distinct cultural equivalents (e.g., Japanese 引き寄せ for Law of Attraction), use the culturally recognized terms

### Wisdom Quotes (31 keys)

- For well-known authors (Rumi, Lao Tzu, Thich Nhat Hanh): use recognized published translations where known
- For less widely-translated quotes: translate directly preserving poetic tone
- Author attributions kept in original romanized form with native script where appropriate

### Content Not Translated

- User-generated content (intentions, gratitudes, scratchpad drafts)
- Author names in attributions
- App icon, assets, font families
